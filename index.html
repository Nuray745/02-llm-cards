What is an LLM?

LLM stands for Large Language Model. It is a type of artificial intelligence model trained on large amounts of text data.

LLMs learn patterns in language and generate human-like text by predicting the next token in a sequence.

Examples of LLMs include GPT-4o by OpenAI, Claude Sonnet 4 by Anthropic, and Gemini 1.5 Pro by Google.

What is a Token?

A token is a small piece of text used by LLMs. It can be a word, part of a word, or even a single character.

Tokens matter because LLMs measure input size and pricing based on tokens.

Example: "Hello, world!" → ["Hello", ",", " world", "!"]

In English, fewer tokens are usually needed compared to Azerbaijani because Azerbaijani words can be longer and more complex.
